# ACM 训练台

面向 ACM/ICPC 选手的一站式训练工具：**算法模板库** + **知识技能树**，另提供原生 Windows 桌面版与账号同步（个人 / 团队）。

## 功能

### 📁 模板库（index.html）
- 选择本地模板目录（Chrome/Edge 文件系统 API，自动记忆），按一级子目录自动分类
- 新建模板：选分类 → 命名 → 粘贴代码或上传文件；支持拖拽上传、重命名、删除、编辑
- 拖拽排序（分类与模板），顺序持久化到 `.acm-order.json`
- 语法高亮（C/C++/Python/Java）、深浅主题、搜索
- **一键整理打印**：自定义标题/栏数/字号，生成封面+目录+正文的 A4 打印视图，双栏自动横向，可另存 PDF

### 🌳 知识技能树（skilltree.html）
- 五大板块（基础·搜索·构造 / 动态规划 / 图论与数据结构 / 数学·博弈·几何 / 字符串与杂项）
- 铜/银/金/了解 四层分级，按巩固值（练习量 × 自评 × 记忆保持）着色
- 刷题记录、奖牌就绪度估算、建议攻克与复习推荐、板块雷达
- 「🎲 练什么？」按个人方向推荐：综合、图论 / DS 手、数学手、DP / 字符串手各自独立推荐；专攻方向只抽本方向及通用基础，候选不足时少推几个，不会跨方向凑数；主攻层与新知识点层级也按本方向的进度计算
- 每个方向下「已练过/自评」与「未练新知识点」独立保存批次、数量和抽取历史，切换回来恢复各自结果。已练范围只抽有记录或自评的知识点（优先薄弱 / 久未复习）；未练范围只抽无记录且未自评、当前层级内已解锁的知识点，不混用两种范围
- 同一范围内已有标签保留到主动「换一批」，增加数量只补缺项，减少后再增加恢复原有标签；练习或自评状态变化时移除不再符合范围的标签。旧版缓存恢复时也会校验范围，清理混入的标签；点击卡片可定位到树上节点
- 与模板库双向关联：知识点 ⇆ 模板文件，一键互跳
- 夜间模式、导出/导入 JSON 备份

### ☁ 账号同步与团队（可选，自建服务）
- 自带零依赖 Node 同步服务（`server/`），支持**个人进度 / 团队共享进度**双轨
- 改动自动推送、打开自动拉取；冲突自动合并：刷题日志按唯一 id 并集去重，等级 / 备注取时间较新一侧，不会丢记录
- 同一账号可在多台电脑、Web 版与桌面版之间同步；队友通过 GitHub Pages 访问 Web 版注册使用
- 模板文件与模板目录句柄仍保存在本机，不参与同步

## 使用

### Web 版（零依赖）
双击 `index.html`（Chrome/Edge）。技能树以 iframe 加载 `skilltree.html`，两文件需同目录。

### 在线 Web 版与队友共享（GitHub Pages + 自建同步服务）
1. 仓库 Settings → Pages：分支 `main`、目录 `/ (root)`，得到 `https://<用户名>.github.io/acm-toolkit/`
2. 部署同步服务：见 [`server/README.md`](server/README.md)（Node + systemd + Caddy 自动 HTTPS，或 Docker；无域名可用 Cloudflare Tunnel）
3. 把服务地址填进 `js/sync-config.js` 或页面右上角「☁」弹窗；队友打开 Pages 注册即可各设备同步

### Windows 桌面版（单 exe）
`native/dist/ACM训练台.exe`（或 Releases 页下载）。首次运行自动解压资源到 `%LOCALAPPDATA%\ACMToolkit`，无安装、无依赖（需 Windows 10/11 自带 WebView2 运行时）。

## 从源码构建桌面版

```powershell
cd native
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物输出到 `native/dist/ACM训练台.exe`。构建使用系统自带 C# 编译器（.NET Framework 4.8），WebView2 SDK 程序集已在 `native/lib/`。

推荐练习与跨设备同步的浏览器回归测试见 [`tests/README.md`](tests/README.md)。

## 数据说明

- 模板文件存储在你自己的本地目录中，程序只负责索引与整理
- 技能树进度、主题偏好、知识点↔模板关联存于浏览器 localStorage（Web 版）或 WebView2 用户数据（桌面版）；换环境可用账号同步，或用技能树的「导出 JSON」迁移
- 登录同步后，进度数据保存在你自建服务器的 `DATA_DIR`（内含密码哈希与进度 JSON），登录令牌只存本机；跨设备合并不会丢失刷题记录
- 个人方向及各方向、各练习范围的推荐批次、数量、历史随所选账号空间同步；同一账号、同一空间在不同电脑上会看到相同推荐；不同方向或不同范围的修改分别合并，同一方向同一范围以较新批次为准。旧版单批次自动迁入「综合」方向，旧范围缓存清理越界标签，服务端无需升级或迁移数据；各设备需要使用新版前端
- 模板文件本身不参与同步，各设备保留自己的模板目录；Web 版与桌面版的模板目录相互独立
